# Tic Tac Toe

A basic Tic Tac Toe game but with an Apple inspired UI/UX, two game modes, and three difficulty levels.

## Features

- **Apple-Inspired UI/UX** 
- **Smooth Animations** 
- **Three Difficulty Levels** 
- **Two Game Modes** 
- **Fully Responsive** 
- **Lightweight** 

## Tech Stack

- **HTML5** 
- **Tailwind CSS** 
- **Vanilla JavaScript** 

## Demo URL

https://tic-tac-toe-two-opal-12.vercel.app/

## AI Usage

Claude sonnet 5.5 was used for sketching out the animations, generating the sound effects and for debugging.
